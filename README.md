Interview Questions
1. What are the different types of missing data?
Missing data can be MCAR (Missing Completely at Random), MAR (Missing At Random), and MNAR (Missing Not At Random).
2. How do you handle categorical variables?
Categorical variables can be handled using encoding techniques like Label Encoding and One-Hot Encoding.
3. What is the difference between normalization and standardization?
Normalization scales data between 0 and 1, while standardization transforms data to have mean 0 and standard deviation 1.
4. How do you detect outliers?
Outliers can be detected using boxplots, IQR method, Z-score, or visualization techniques.
5. Why is preprocessing important in ML?
Preprocessing improves data quality and helps machine learning models perform better and give accurate results.
6. What is one-hot encoding vs label encoding?
One-hot encoding creates binary columns for each category, while label encoding assigns numerical values to categories.
7. How do you handle data imbalance?
Data imbalance can be handled using oversampling, undersampling, or SMOTE technique.
8. Can preprocessing affect model accuracy?
Yes, proper preprocessing can significantly improve accuracy, while poor preprocessing can reduce model performance.
